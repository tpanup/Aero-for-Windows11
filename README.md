## 三、控制中心

- **玻璃透明度** 45% ~ 100%
  100% = 不透的“假玻璃”；调低真的半透 —— 代价是能隐约看到被盖住的原生标签栏。
- **壁纸模糊强度** 0 ~ 80（改动会重算玻璃底图，约 100ms）
- **玻璃色彩**：天蓝 / 青 / 绿 / 紫 / 银灰 / 琥珀
- **给所有资源管理器窗口都套壳**（关掉只套当前前台窗口）
- **在右下角显示提示条**
- 右下角常显：`v1.0 · 反馈：3807318397@qq.com`
- 配置保存在 `%APPDATA%\ATW11\settings.json`

## 四、实现要点

### 1. 只画“框”，不画“内容”
覆盖层是一块真正的全透明玻璃：除了玻璃壳和提示条，其它像素 alpha 全为 0，鼠标直接穿透。
所以资源管理器本身完全正常，我们只是“给它描了个 Win7 边”。

### 2. 玻璃的形状
外壳 = 外圆角矩形 − 内孔（`CombinedGeometry(Exclude)`），内孔底角 8px 圆角吻合 Win11 窗口圆角；
顶栏 38 DIP 正好盖住原生标签栏（本机实测 ≈35 DIP）。

### 3. 重叠不穿模（v1.0 重点）
`EnumWindows` 的顺序就是 Z 序。对每个壳，记下**在它上面**的所有可见窗口矩形，
再用 `Clip = 自身范围 − 那些矩形` 把玻璃裁掉被压住的部分。
所以两个窗口重叠时，后面那个的玻璃边框会在前面窗口的边缘被干净切断 —— 就像真的被挡住一样。
另外：按钮如果被别的窗口压住，也不响应点击（避免点到"看不见的按钮"）。

### 4. 顶栏拖动自己实现
不转交原生（实测某些组合下窗口不动），而是自己 `SetCapture` + 记下光标与窗口原点，移动时 `SetWindowPos`。
点三个按钮和拖动顶栏都**用光标的真实物理位置**判定 —— 跨 DPI 感知时消息里的 lParam 会被系统改写，不能信。

### 5. 壁纸模糊而不是屏幕截图
资源管理器不透明，它背后"透"出来的应该什么都没有；Win7 Aero 玻璃里透的其实是**壁纸**。
所以直接读系统壁纸、按"填充"铺满屏幕、做一次高斯模糊，每块玻璃按自己的屏幕坐标取一块。

### 6. 全程只在内存里
截图 / 模糊 / 缩放全是内存位图，不落盘；只有 `settings.json` 会写到 `%APPDATA%`。

## 六、已知限制

- 只铺主显示器；副屏窗口不会被描边。
- 顶栏拖动不参与 Aero Snap（贴边分屏请用 `Win+←/→`）。
- 透明度调很低时，被盖住的原生标签栏会透出来（真半透明的物理后果）。
- 需要 .NET 桌面运行时；项目里加了 `RollForward=LatestMajor`，.NET 8 目标可直接跑在更新的运行时上。
