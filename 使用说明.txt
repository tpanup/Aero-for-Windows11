========================================
 ATW11 · Aero to Windows 11   v1.0
 给资源管理器套上 Win7 玻璃外壳
 反馈邮箱：3807318397@qq.com
========================================

【怎么开始】
1. 双击本文件夹里的「ATW11.exe」（或者「ATW11 启动」快捷方式）。
2. 右下角托盘会出现一个小图标，第一次启动会弹个气泡提示。
3. 打开任意文件夹窗口，它四周就会套上 Win7 风格的蓝色玻璃边框，
   顶部是一条标题栏（文件夹图标 + 名字 + ─ □ ✕），Win11 原来的标签栏被盖住。

【怎么用】
  按住蓝色顶栏拖动   移动窗口
  双击顶栏           最大化 / 还原
  ─ 按钮             最小化
  □ 按钮             最大化 / 还原
  ✕ 按钮             关闭这个文件夹窗口（鼠标移上去会变红发光）
  Esc                退出整个程序

【两个窗口重叠会怎样】
  会自动"互相遮挡"：后面那个窗口的玻璃边框，在前面窗口的边缘被干净切断，
  不会糊到前面窗口的内容上。被别的程序压住的按钮也不会误触发。

【控制中心】
  打开方式：
    · 托盘图标右键 → "打开控制中心"
    · 双击托盘图标
    · 双击桌面的「ATW11 控制中心」快捷方式
  里面可以调：
    玻璃透明度   45%~100%（调低真的会变半透，会隐约看到被盖住的标签栏）
    壁纸模糊强度 0~80（玻璃里透出的壁纸有多糊）
    玻璃色彩     天蓝 / 青 / 绿 / 紫 / 银灰 / 琥珀
    开关         给所有窗口套壳（关掉只套前台窗口）、显示右下角提示条
    按钮         暂停装饰 / 恢复默认 / 退出程序
  所有改动即时生效，并自动记住（%APPDATA%\ATW11\settings.json）。
  窗口右下角常显版本号和反馈邮箱。

【退出】
  · 按 Esc
  · 或托盘右键 → 退出 ATW11
  · 或控制中心右下角「退出程序」

【常见问题】
  · 双击没反应：可能已经在后台运行了（看右下角托盘 ▲ 里）；重复启动只会把控制中心叫出来。
  · 找不到托盘图标：Win11 默认把新图标收进任务栏的 ▲ 溢出区，点 ▲ 就能看到，
    也可以把它拖到任务栏上常显。
  · 玻璃壳没出现：把那个文件夹窗口点一下切到前台，或看看它是不是被别的窗口挡住了。
  · 顶栏拖不动：确认是按在蓝色顶栏上（不是窗口内容区）。
  · 想让它彻底消失：托盘右键 → 退出 ATW11。
