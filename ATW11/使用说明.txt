========================================
 ATW11 · Aero to Windows 11   v1.0
 给资源管理器套上 Win7 玻璃外壳
 反馈邮箱：3807318397@qq.com
========================================

【这是什么】
一个 Windows 桌面小工具：给 Windows 11 的"文件资源管理器"套一圈 Win7 Aero 风格的玻璃外壳。
不注入 DLL、不 Hook 别的进程、不碰系统文件 —— 用的是"全屏透明覆盖层 + 壁纸重绘"的做法。

【怎么跑起来】
  方式一（源码，本目录就是工程）：
      dotnet build -c Release
      dotnet run
  方式二（成品）：用发布出来的 ATW11.exe，双击即可。

【怎么用】
  1. 启动后右下角托盘会出现一个小图标（Win11 可能把它收在任务栏的 ▲ 溢出区里）。
  2. 打开任意文件夹窗口，它四周就会套上 Win7 风格的蓝色玻璃边框，
     顶部是一条标题栏（文件夹图标 + 名字 + ─ □ ✕），Win11 原来的标签栏被盖住。
  3. 按住蓝色顶栏拖动 = 移动窗口；双击顶栏 = 最大化 / 还原。
  4. ─ □ ✕ 三个按钮操作的是真窗口；鼠标悬停有光效，关闭按钮变红发光。

【两个窗口重叠会怎样】
  会自动"互相遮挡"：后面那个窗口的玻璃边框，在前面窗口的边缘被干净切断，
  不会糊到前面窗口的内容上。被别的程序压住的按钮也不会误触发。

【控制中心】
  托盘图标右键 → "打开控制中心"（或双击托盘图标）。
  可以调：玻璃透明度 / 壁纸模糊强度 / 6 套玻璃色彩 / 是否给所有窗口套壳 / 是否显示提示条。
  改动即时生效并自动保存到 %APPDATA%\ATW11\settings.json。
  窗口右下角常显版本号和反馈邮箱。

【退出】
  按 Esc，或托盘右键 → 退出 ATW11，或控制中心右下角"退出程序"。

【常见问题】
  · 双击没反应：可能已经在后台运行了（看右下角托盘 ▲ 里）；重复启动只会把控制中心叫出来。
  · 找不到托盘图标：Win11 默认把新图标收进任务栏的 ▲ 溢出区，点 ▲ 就能看到，
    也可以把它拖到任务栏上常显。
  · 玻璃壳没出现：把那个文件夹窗口点一下切到前台，或看看它是不是被别的窗口挡住了。
  · 顶栏拖不动：确认是按在蓝色顶栏上（不是窗口内容区）。
  · 想让它彻底消失：托盘右键 → 退出 ATW11。

【已知限制】
  · 只铺主显示器；副屏窗口不会被描边。
  · 顶栏拖动不参与 Aero Snap（贴边分屏请用 Win+←/→）。
  · 玻璃透明度调很低时，被盖住的原生标签栏会透出来（真半透明的物理后果）。
  · 需要 .NET 桌面运行时。
